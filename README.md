# Academic PPT System

Auditable and extensible engineering system for academic presentation automation.

## Goal

可审计、可扩展的学术/商业答辩 PPT 自动化工程系统。

## Major workflows

- **PPT Core** — 学术/商业答辩 PPT 产品与核心引擎
- **PowerPoint execution / qualification** — PowerPoint Desktop 执行与资格认证
- **OSS capability harvesting** — 开源方案能力采集（pinned upstream + adapter）
- **provider / adapter integration** — 提供方/适配器集成
- **QA / evidence / qualification** — 质量保证、证据链与资格判定

## Status

仓库目前处于**工程开发阶段**（engineering development）。

本仓库**不宣称**：`QUALIFIED`、`CERTIFIED`、`GOLD`、`RELEASED`。

任何此类状态只能由未来独立的 Gate 正式授予，并在对应证据中记录。
